Chapter 1: Computer System

What is a Computer?

A computer is an electronic device that accepts data as input, processes it according to instructions and produces useful output.

Basic Working

Input → Processing → Output
Example:

When you enter two numbers into a calculator:

Input → 10 and 20
Processing → Addition
Output → 30

Hardware

Hardware refers to the physical components of a computer.

Examples: Keyboard, Mouse, Monitor, CPU, Printer and Hard Disk.

Software

Software is a collection of programs/instructions that tells a computer how to perform tasks.

Examples: Operating System, Web Browser, Word Processor.
⭐ Hardware can be physically touched, while software is a collection of instructions/programs.

Chapter 2: Emerging Trends

Artificial Intelligence

Artificial Intelligence (AI) is a field of computing concerned with systems that can perform tasks requiring capabilities such as learning, pattern recognition and decision-making.

Machine Learning

Machine Learning is a method in which computer systems learn patterns from data and use them to make predictions or decisions.

Internet of Things

IoT refers to connected physical devices that can collect, exchange and process data through networks.

Cloud Computing

Cloud computing provides computing resources and services over a network.

Examples of cloud services include online storage, hosted applications and computing resources.

AR and VR

AR (Augmented Reality) adds digital information to the user's view of the real world.

VR (Virtual Reality) creates an immersive computer-generated environment.

⭐ Emerging technologies are important for understanding how modern computing is used in education, healthcare, business and other fields.

Chapter 3: Python Basics

What is Python?

Python is a high-level programming language known for its readable syntax and wide range of applications.

First Python Program

print("Hello World")

The print() function displays output on the screen.

Variables

A variable is a name used to refer to a value stored in a program.

name = "Rahul" age = 17 marks = 85

Input

name = input("Enter your name: ") print(name)

Type Conversion

age = int(input("Enter age: ")) print(age)
⭐ input() normally returns text. Use int() or float() when numerical input is required.

Chapter 4: Operators and Expressions

Arithmetic Operators

+ → Addition
- → Subtraction
* → Multiplication
/ → Division
// → Floor Division
% → Modulus
** → Exponentiation
a = 10 b = 3 print(a + b) print(a - b) print(a * b) print(a / b) print(a % b)

Comparison Operators

==   !=   >   <   >=   <=

Logical Operators

and    or    not
Example:

10 > 5 and 8 > 3
Result: True

Chapter 5: Conditional Statements

if Statement

The if statement executes a block of code when its condition is true.

marks = 75 if marks >= 40: print("Pass")

if-else

marks = 35 if marks >= 40: print("Pass") else: print("Fail")

if-elif-else

marks = 82 if marks >= 90: print("Excellent") elif marks >= 60: print("Good") else: print("Needs Improvement")

Chapter 6: Loops

for Loop

A for loop is commonly used to repeat a block of code over a sequence or range.

for i in range(1, 6): print(i)

while Loop

i = 1 while i <= 5: print(i) i = i + 1
⭐ Make sure the condition of a while loop eventually becomes false, otherwise the loop may continue indefinitely.

Chapter 7: Lists

A list is a collection that can store multiple values in a single variable.

marks = [80, 75, 92, 68] print(marks) print(marks[0])

Important List Operations

append() → adds an element
insert() → inserts an element at a position
remove() → removes a value
pop() → removes an element
sort() → sorts the list
reverse() → reverses the list
len() → returns number of elements
numbers = [5, 2, 8] numbers.append(10) numbers.sort() print(numbers)

Chapter 8: Dictionaries

A dictionary stores data in the form of key-value pairs.

student = { "name": "Aman", "age": 17, "marks": 85 } print(student["name"])

Important Methods

keys() → returns keys
values() → returns values
items() → returns key-value pairs
update() → updates dictionary
clear() → removes all elements
Example:

In the dictionary:
"name" is the key.
"Aman" is its value.

Chapter 9: Database Concepts

Database

A database is an organized collection of data that can be stored, managed and retrieved efficiently.

DBMS

A Database Management System (DBMS) is software used to create, manage and access databases.

Table

In a relational database, data is commonly organized into tables containing rows and columns.

Student Table

Roll No | Name | Marks
1 | Aman | 85
2 | Riya | 91

Primary Key

A primary key uniquely identifies each record in a table.

Chapter 10: SQL

SQL stands for Structured Query Language. It is used to work with relational databases.

Create Database

CREATE DATABASE school;

Create Table

CREATE TABLE student ( roll_no INT, name VARCHAR(50), marks INT );

Insert Data

INSERT INTO student VALUES (1, 'Aman', 85);

Display Data

SELECT * FROM student;

Search Data

SELECT * FROM student WHERE marks > 80;

Update Data

UPDATE student SET marks = 90 WHERE roll_no = 1;

Delete Data

DELETE FROM student WHERE roll_no = 1;
⭐ Remember the basic SQL commands: CREATE, SELECT, INSERT, UPDATE and DELETE.
