1. Database Query Using SQL

Database

A database is an organised collection of related data that can be stored, managed and retrieved efficiently.

Important SQL Commands

CREATE DATABASE school; CREATE TABLE students( rollno INT, name VARCHAR(30), marks INT );

INSERT

INSERT INTO students VALUES(1,'Rahul',85);

SELECT

SELECT * FROM students;

WHERE

SELECT name, marks FROM students WHERE marks > 80;

UPDATE

UPDATE students SET marks = 90 WHERE rollno = 1;

DELETE

DELETE FROM students WHERE rollno = 1;

ORDER BY

SELECT * FROM students ORDER BY marks DESC;

GROUP BY

SELECT city, COUNT(*) FROM students GROUP BY city;

HAVING

SELECT city, AVG(marks) FROM students GROUP BY city HAVING AVG(marks) > 70;

Aggregate Functions

  • MAX() → highest value
  • MIN() → lowest value
  • AVG() → average
  • SUM() → total
  • COUNT() → number of values/rows
Exam Tip: WHERE rows ko filter karta hai, while HAVING grouped results ko filter karta hai.

3. Working With Multiple Tables

Why Join?

A join is used to combine related information stored in multiple tables.

Equi Join

SELECT students.name, marks.score FROM students, marks WHERE students.rollno = marks.rollno;
Example:
Students table mein student details ho sakti hain aur Marks table mein marks. Common roll number ke through dono tables ko connect kiya ja sakta hai.

4. Data Handling Using Pandas

What is Pandas?

Pandas is a Python library used for data handling and analysis.

Import Pandas

import pandas as pd

Series

A Series is a one-dimensional labelled data structure.

import pandas as pd s = pd.Series([10,20,30,40]) print(s)

Series From Dictionary

data = { "Maths": 80, "Physics": 75, "Chemistry": 85 } s = pd.Series(data) print(s)

Head and Tail

s.head() s.tail()
Remember: head() beginning ke records aur tail() last ke records show karta hai.

5. DataFrame

What is DataFrame?

A DataFrame is a two-dimensional labelled data structure consisting of rows and columns.

Create DataFrame

import pandas as pd data = { "Name":["Aman","Riya","Karan"], "Marks":[80,90,75] } df = pd.DataFrame(data) print(df)

Select Column

df["Name"]

Add Column

df["Grade"] = ["B","A","B"]

Delete Column

df.drop("Grade", axis=1, inplace=True)

Rename Column

df.rename( columns={"Marks":"Score"}, inplace=True )

Boolean Indexing

df[df["Marks"] > 80]
Exam Tip: Series = one-dimensional, DataFrame = two-dimensional.

6. CSV Files With Pandas

Read CSV File

df = pd.read_csv("students.csv") print(df)

Export DataFrame to CSV

df.to_csv("output.csv", index=False)
Use:
CSV files ko DataFrame mein import karke data analyse ya modify kiya ja sakta hai, aur processed data ko wapas CSV file mein export kiya ja sakta hai.

7. Data Visualization Using Matplotlib

What is Matplotlib?

Matplotlib is a Python library used to create graphs and visualisations.

Import

import matplotlib.pyplot as plt

Line Plot

x = [1,2,3,4] y = [10,20,15,30] plt.plot(x,y) plt.xlabel("X") plt.ylabel("Y") plt.title("Line Plot") plt.show()

Bar Graph

names = ["A","B","C"] marks = [80,90,70] plt.bar(names,marks) plt.title("Marks") plt.show()

Histogram

marks = [45,50,55,60,60,70,75,80] plt.hist(marks) plt.title("Marks Distribution") plt.show()

Useful Plot Functions

  • xlabel() → X-axis label
  • ylabel() → Y-axis label
  • title() → graph title
  • legend() → identifies plotted data
  • savefig() → saves graph
plt.savefig("graph.png")

8. Computer Networks

Network

A computer network is a group of connected devices that can communicate and share resources.

Types of Networks

  • PAN → Personal Area Network
  • LAN → Local Area Network
  • MAN → Metropolitan Area Network
  • WAN → Wide Area Network

Network Devices

  • Modem → connects a network to communication service.
  • Hub → broadcasts data to connected devices.
  • Switch → forwards data to the appropriate device.
  • Router → connects different networks and forwards packets.
  • Repeater → regenerates signals.
  • Gateway → connects networks using different protocols.

9. Network Topologies

Star Topology

All devices are connected to a central device such as a switch.

Bus Topology

Devices share a common communication line.

Tree Topology

It has a hierarchical arrangement of connected devices.

Mesh Topology

Devices have multiple interconnections with other devices.

Quick Memory:
Star → Central device
Bus → Common backbone
Tree → Hierarchical
Mesh → Multiple connections

10. Internet and Web

Internet

The Internet is a global network of interconnected computer networks.

WWW

World Wide Web is a system of interlinked web resources accessed through the Internet.

URL

URL stands for Uniform Resource Locator. It identifies the location of a resource on the Web.

Website vs Webpage

  • Website → collection of related web pages.
  • Webpage → an individual page/document on a website.

Static vs Dynamic Web Page

  • Static → content generally remains fixed unless manually changed.
  • Dynamic → content can be generated or changed based on data or user interaction.

11. Societal Impacts

Digital Footprint

The information and traces a person leaves through activities performed online are called a digital footprint.

Plagiarism

Plagiarism means presenting another person's work or ideas as your own without proper acknowledgement.

Copyright

Copyright gives creators legal rights over their original creative works, subject to applicable law.

Phishing

Phishing is a fraudulent attempt to obtain sensitive information by pretending to be a trustworthy person or organisation.

Cyber Bullying

Cyber bullying means using digital communication to repeatedly harass, threaten or humiliate another person.

FOSS

FOSS means Free and Open Source Software. Its source code is available under the applicable open-source licence.

E-Waste

Discarded electronic devices and components are called electronic waste or e-waste. Proper collection, recycling and disposal help reduce environmental and health risks.
