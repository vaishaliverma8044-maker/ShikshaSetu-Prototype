Complete C++ Programming Notes

Beginner-friendly notes covering the important fundamentals of C++ programming with definitions, explanations, examples and programs.

1. Introduction to C++

Definition

C++ is a general-purpose programming language developed by Bjarne Stroustrup. It supports both procedural and object-oriented programming.

Why Learn C++?

  • It is widely used for learning programming fundamentals.
  • It is commonly used for Data Structures and Algorithms.
  • It supports Object-Oriented Programming.
  • It provides good control over memory and system resources.
  • It is useful for competitive programming.

Basic C++ Program

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World";

    return 0;
}
Output:
Hello World

Important Points

  • #include <iostream> is used for input/output.
  • main() is the starting point of the program.
  • cout is used to display output.
  • return 0 indicates successful execution.

2. Variables and Data Types

Variable

A variable is a named memory location used to store a value.

Example

int age = 18;
float marks = 85.5;
char grade = 'A';

Common Data Types

Data Type Purpose Example
int Integer values 10
float Decimal values 10.5
double More precise decimal values 25.6789
char Single character 'A'
bool True or false true
string Collection of characters "Hello"

Input from User

#include <iostream>
using namespace std;

int main()
{
    int age;

    cout << "Enter age: ";
    cin >> age;

    cout << "Your age is " << age;

    return 0;
}
Remember: cin is generally used to take input and cout is used to display output.

3. Operators in C++

Operators are symbols used to perform operations on values and variables.

Arithmetic Operators

Operator Meaning Example
+ Addition a + b
- Subtraction a - b
* Multiplication a * b
/ Division a / b
% Remainder a % b

Relational Operators

  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to

Logical Operators

  • && AND
  • || OR
  • ! NOT

Example

int a = 10;
int b = 5;

cout << a + b;
cout << a - b;
cout << a * b;

4. Conditional Statements

Conditional statements are used when a program needs to make decisions based on a condition.

if Statement

int age = 18;

if(age >= 18)
{
    cout << "Eligible";
}

if-else Statement

int number;

cin >> number;

if(number % 2 == 0)
{
    cout << "Even";
}
else
{
    cout << "Odd";
}

else-if Ladder

int marks;

cin >> marks;

if(marks >= 90)
{
    cout << "Grade A";
}
else if(marks >= 75)
{
    cout << "Grade B";
}
else if(marks >= 50)
{
    cout << "Grade C";
}
else
{
    cout << "Fail";
}
Exam Tip: Always check the conditions from top to bottom in an if-else-if ladder.

5. Loops in C++

Loops are used to execute a block of statements repeatedly.

Types of Loops

  1. for loop
  2. while loop
  3. do-while loop

for Loop

for(int i = 1; i <= 5; i++)
{
    cout << i << endl;
}
Output:
1
2
3
4
5

while Loop

int i = 1;

while(i <= 5)
{
    cout << i << endl;
    i++;
}

do-while Loop

int i = 1;

do
{
    cout << i << endl;
    i++;
}
while(i <= 5);
Important: A do-while loop executes its body at least once because the condition is checked after the body.

6. Functions

A function is a block of code designed to perform a specific task. Functions help make programs modular and reusable.

Basic Function

#include <iostream>
using namespace std;

void greet()
{
    cout << "Welcome to C++";
}

int main()
{
    greet();

    return 0;
}

Function with Parameters

#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result = add(10, 20);

    cout << result;

    return 0;
}
Output:
30

Advantages of Functions

  • Code reusability
  • Better program organization
  • Easier debugging
  • Reduces repeated code

7. Arrays and Strings

Array

An array is a collection of elements of the same data type stored in contiguous memory locations.

Example

int marks[5] = {80, 75, 90, 85, 70};

cout << marks[0];
Output:
80

Array Traversal

int numbers[5] = {10, 20, 30, 40, 50};

for(int i = 0; i < 5; i++)
{
    cout << numbers[i] << endl;
}

String

A string is a sequence of characters. 

#include <iostream>
#include <string>
using namespace std;

int main()
{
    string name;

    cout << "Enter your name: ";
    cin >> name;

    cout << "Hello " << name;

    return 0;
}
Important: Array indexing normally starts from 0.

8. Pointers Basics

A pointer is a variable that stores the memory address of another variable.

Example

int number = 10;

int *ptr = &number;

cout << number << endl;
cout << &number << endl;
cout << ptr << endl;
cout << *ptr << endl;

Important Symbols

  • & can be used to obtain an address.
  • * is used with a pointer to access the stored value.
Remember: A pointer stores an address, not the actual value of the variable it points to.

9. Object-Oriented Programming Basics

Object-Oriented Programming (OOP) is a programming approach based on objects and classes.

Important OOP Concepts

  • Class
  • Object
  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

Class and Object Example

#include <iostream>
using namespace std;

class Student
{
public:

    string name;
    int age;

    void display()
    {
        cout << name << endl;
        cout << age << endl;
    }
};

int main()
{
    Student s1;

    s1.name = "Rahul";
    s1.age = 18;

    s1.display();

    return 0;
}
Output:
Rahul
18

Class

A class is a blueprint or template used to create objects.

Object

An object is an instance of a class.
