Lesson 1

Introduction to C++

Definition

C++ is a general-purpose programming language used to create software, applications, games, operating systems and many other types of programs.

Easy Explanation

C++ allows us to give instructions to a computer. We write instructions in C++ code and the compiler converts that code into a form that the computer can understand.

Example

The following program prints "Hello World" on the screen. 

#include <iostream>
using namespace std;

int main() {
    cout << "Hello World";
    return 0;
}

Output

Hello World

Important Points

  • C++ is a programming language.
  • C++ programs are usually compiled before execution.
  • main() is the starting point of a C++ program.
  • cout is used to display output.
Lesson 2

Variables and Data Types

Definition

A variable is a named memory location used to store data. A data type tells the computer what type of data a variable can store.

Easy Explanation

Suppose we want to store a student's age, marks or name. We create variables for these values.

Common Data Types

  • int → stores whole numbers
  • float → stores decimal numbers
  • char → stores a single character
  • bool → stores true or false

Example

#include <iostream>
using namespace std;

int main() {

    int age = 18;
    float marks = 85.5;
    char grade = 'A';
    bool passed = true;

    cout << age << endl;
    cout << marks << endl;
    cout << grade << endl;
    cout << passed;

    return 0;
}

Output

18
85.5
A
1

Important Points

  • Every variable has a data type.
  • Variable names should be meaningful.
  • Use int for whole numbers.
  • Use float for decimal values.
Lesson 3

Operators

Definition

Operators are symbols used to perform operations on values and variables.

Easy Explanation

Operators allow us to perform mathematical calculations, comparisons and logical operations.

Common Arithmetic Operators

  • + → Addition
  • - → Subtraction
  • * → Multiplication
  • / → Division
  • % → Remainder

Example

#include <iostream>
using namespace std;

int main() {

    int a = 10;
    int b = 3;

    cout << a + b << endl;
    cout << a - b << endl;
    cout << a * b << endl;
    cout << a / b << endl;
    cout << a % b;

    return 0;
}

Output

13
7
30
3
1

Important Points

  • + adds two values.
  • - subtracts values.
  • * performs multiplication.
  • / performs division.
  • % gives the remainder.
Lesson 4

If-Else Statements

Definition

An if-else statement is used to make decisions in a program.

Easy Explanation

The program checks a condition. If the condition is true, one block of code runs. Otherwise, the else block runs.

Example

#include <iostream>
using namespace std;

int main() {

    int marks = 75;

    if (marks >= 40) {
        cout << "Pass";
    }
    else {
        cout << "Fail";
    }

    return 0;
}

Output

Pass

Important Points

  • if checks a condition.
  • else runs when the condition is false.
  • Conditions usually use comparison operators.
Lesson 5

Loops

Definition

A loop is used to execute the same block of code repeatedly.

Easy Explanation

If we need to perform the same task many times, instead of writing the same code again and again, we can use a loop.

Types of Loops

  • for loop
  • while loop
  • do-while loop

Example

#include <iostream>
using namespace std;

int main() {

    for (int i = 1; i <= 5; i++) {
        cout << i << endl;
    }

    return 0;
}

Output

1
2
3
4
5

Important Points

  • Loops reduce repeated code.
  • for loop is useful when repetitions are known.
  • Always make sure the loop can eventually stop.
Lesson 6

Functions

Definition

A function is a block of code designed to perform a specific task.

Easy Explanation

Functions help us divide a large program into smaller, reusable parts.

Example

#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {

    int result = add(10, 20);

    cout << result;

    return 0;
}

Output

30

Important Points

  • A function performs a specific task.
  • Functions can accept parameters.
  • A function can return a value.
  • Functions improve code reusability.
Lesson 7

Arrays

Definition

An array is a collection of elements of the same data type stored together.

Easy Explanation

Instead of creating separate variables for many values, we can store them inside one array.

Example

#include <iostream>
using namespace std;

int main() {

    int marks[3] = {80, 75, 90};

    cout << marks[0] << endl;
    cout << marks[1] << endl;
    cout << marks[2];

    return 0;
}

Output

80
75
90

Important Points

  • Array stores multiple values of the same type.
  • Array indexing starts from 0.
  • The first element is at index 0.
  • The second element is at index 1.
Lesson 8

Object-Oriented Programming Basics

Definition

Object-Oriented Programming (OOP) is a programming approach based on objects and classes.

Easy Explanation

A class can be thought of as a blueprint, while an object is an actual instance created from that blueprint.

Example

#include <iostream>
using namespace std;

class Student {

public:

    string name;

    void display() {
        cout << "Student: " << name;
    }
};

int main() {

    Student s1;

    s1.name = "Rahul";

    s1.display();

    return 0;
}

Output

Student: Rahul

Important Points

  • A class is a blueprint.
  • An object is created from a class.
  • OOP helps organize large programs.
  • Important OOP concepts include class, object, inheritance, polymorphism and encapsulation.
