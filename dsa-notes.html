🧩 DSA Beginner Notes

Learn the fundamentals of Data Structures and Algorithms step by step.

1. What is DSA?

DSA stands for Data Structures and Algorithms.

A Data Structure is a way of organizing and storing data. An Algorithm is a step-by-step procedure used to solve a problem.

Simple example: An array stores numbers, while an algorithm can be used to find the largest number in that array.

2. Why Learn DSA?

  • Helps solve programming problems efficiently.
  • Improves logical thinking.
  • Useful for coding interviews.
  • Forms the foundation of advanced computer science topics.

3. Time Complexity

Time complexity describes how the running time of an algorithm changes as the input size increases.

ComplexityMeaning
O(1)Constant time
O(log n)Logarithmic time
O(n)Linear time
O(n log n)Common efficient sorting complexity
O(n²)Quadratic time

4. Arrays

An array stores multiple elements of the same data type in contiguous memory locations. 

int arr[5] = {10, 20, 30, 40, 50};

cout << arr[0];

Important: Array indexing starts from 0.

5. Searching

Linear Search

Linear search checks elements one by one until the required element is found. 

for(int i = 0; i < n; i++) {
    if(arr[i] == key) {
        cout << "Found";
        break;
    }
}

Time Complexity: O(n)

Binary Search

Binary search repeatedly divides a sorted array into halves.

Time Complexity: O(log n)

6. Sorting

Sorting means arranging data in a particular order, such as ascending or descending.

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort

Bubble Sort idea

Compare adjacent elements and swap them when they are in the wrong order.

7. Stack

A stack follows LIFO — Last In, First Out.

Example: A stack of plates.

  • Push → add an element
  • Pop → remove the top element
  • Top → view the top element

8. Queue

A queue follows FIFO — First In, First Out.

Example: People standing in a line.

  • Enqueue → add element
  • Dequeue → remove element
  • Front → first element

9. Linked List

A linked list consists of nodes. Each node contains data and a link to another node. 

struct Node {
    int data;
    Node* next;
};

Unlike arrays, linked-list elements do not need to occupy contiguous memory locations.

10. Recursion

Recursion occurs when a function calls itself to solve smaller versions of the same problem. 

int factorial(int n) {

    if(n == 0)
        return 1;

    return n * factorial(n - 1);
}

A recursive solution needs a proper base case.

11. Trees

A tree is a hierarchical data structure consisting of nodes connected by edges.

  • Root → top node
  • Parent → node having children
  • Child → node connected below a parent
  • Leaf → node with no children

12. Graphs

A graph consists of vertices and edges.

Graphs can represent roads, social networks, computer networks and many other relationships.
