Chapter 1: Sets

1. What is a Set?

A set is a well-defined collection of distinct objects. The objects of a set are called its elements or members.

Example:
A = {1, 2, 3, 4, 5}

Here 1, 2, 3, 4 and 5 are elements of set A.

2. Representation of Sets

Sets can mainly be represented in two ways:

Roster Form: Elements are written inside braces.

A = {2, 4, 6, 8}

Set-builder Form: A rule describing the elements is used.

A = {x : x is an even natural number less than 10}

3. Important Types of Sets

Empty Set: A set having no element.

Finite Set: A set having a limited number of elements.

Infinite Set: A set having infinitely many elements.

Universal Set: The set containing all objects under consideration.

4. Important Formula

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
Solved Example:

If n(A) = 20, n(B) = 15 and n(A ∩ B) = 5, find n(A ∪ B).

n(A ∪ B) = 20 + 15 − 5
= 30
⭐ Remember: Union means combining elements, while intersection means elements common to both sets.

Chapter 2: Relations and Functions

1. Relation

A relation describes a connection between elements of two sets.

If A = {1, 2} and B = {3, 4}, then

A × B = {(1,3), (1,4), (2,3), (2,4)}

2. Cartesian Product

The Cartesian product of A and B is the set of all ordered pairs (a,b), where a ∈ A and b ∈ B.

n(A × B) = n(A) × n(B)

3. Function

A function is a relation in which every element of the domain is associated with exactly one element of the codomain.

Example:
f(x) = 2x + 1

For x = 2:
f(2) = 2(2) + 1 = 5
⭐ In a function, one input cannot have two different outputs.

Chapter 3: Trigonometric Functions

1. Basic Ratios

sin θ = Perpendicular / Hypotenuse

cos θ = Base / Hypotenuse

tan θ = Perpendicular / Base

2. Reciprocal Relations

cosec θ = 1 / sin θ
sec θ = 1 / cos θ
cot θ = 1 / tan θ

3. Important Identities

sin²θ + cos²θ = 1

1 + tan²θ = sec²θ

1 + cot²θ = cosec²θ
Example:

If sin θ = 3/5, then using sin²θ + cos²θ = 1:

(3/5)² + cos²θ = 1
9/25 + cos²θ = 1
cos²θ = 16/25
cos θ = 4/5

Chapter 4: Complex Numbers

1. Introduction

A complex number is generally written in the form:

z = a + ib

where a and b are real numbers and i = √−1.

2. Important Property

i² = −1

3. Example

Let z = 3 + 4i.

Real part = 3
Imaginary part = 4

4. Modulus

|z| = √(a² + b²)
For z = 3 + 4i:

|z| = √(3² + 4²)
= √25
= 5

Chapter 5: Quadratic Equations

1. Standard Form

ax² + bx + c = 0
where a ≠ 0

2. Quadratic Formula

x = [−b ± √(b² − 4ac)] / 2a

3. Discriminant

D = b² − 4ac

The discriminant helps determine the nature of the roots.

Example:

x² − 5x + 6 = 0

Here a = 1, b = −5, c = 6.

D = (−5)² − 4(1)(6)
= 25 − 24
= 1

Chapter 6: Sequence and Series

Arithmetic Progression

An arithmetic progression (AP) is a sequence in which the difference between consecutive terms is constant.

Example:
2, 5, 8, 11, 14, ...

Common difference = 3

Important Formulas

nth term:
aₙ = a + (n − 1)d

Sum of n terms:
Sₙ = n/2 [2a + (n − 1)d]
Example:

Find the 10th term of: 2, 5, 8, 11, ...

a = 2, d = 3, n = 10

a₁₀ = 2 + (10−1)3
= 2 + 27
= 29
