1. Relations and Functions

Relation

A relation describes a connection between elements of two sets.

Important Types of Relations

  • Reflexive Relation
  • Symmetric Relation
  • Transitive Relation
  • Equivalence Relation

Function

A function from A to B assigns every element of A exactly one element of B.

f : A → B

Composition of Functions

(f ∘ g)(x) = f(g(x))
Example:
If f(x)=2x and g(x)=x+1,
then (f∘g)(x)=f(x+1)=2x+2.

2. Inverse Trigonometric Functions

Important Functions

sin⁻¹x, cos⁻¹x, tan⁻¹x

Important Results

sin⁻¹x + cos⁻¹x = π/2
tan⁻¹x + cot⁻¹x = π/2
tan⁻¹x + tan⁻¹y = tan⁻¹[(x+y)/(1-xy)]
Exam Tip: Inverse trigonometric questions mein principal value range carefully check karo.

3. Matrices

Matrix

A matrix is a rectangular arrangement of numbers in rows and columns.

A = [aᵢⱼ]

Types of Matrices

  • Row Matrix
  • Column Matrix
  • Square Matrix
  • Zero Matrix
  • Diagonal Matrix
  • Identity Matrix

Matrix Addition

Matrices can be added when they have the same order.

A + B = [aᵢⱼ + bᵢⱼ]

Transpose

(Aᵀ)ᵀ = A
Example:
If A = [[1,2],[3,4]], then
Aᵀ = [[1,3],[2,4]]

4. Determinants

Determinant of 2 × 2 Matrix

|a b|
|c d| = ad - bc

Minor

The minor of an element is obtained by deleting its row and column and taking the determinant of the remaining elements.

Cofactor

Aᵢⱼ = (-1)ⁱ⁺ʲ Mᵢⱼ

Area of Triangle

Area = 1/2 | x₁(y₂-y₃) + x₂(y₃-y₁) + x₃(y₁-y₂) |
Important: Determinant zero hone par corresponding equations may have special relationships such as dependent equations.

5. Continuity and Differentiability

Continuity

A function f(x) is continuous at x=a when:

lim x→a f(x) = f(a)

Differentiation

d/dx(xⁿ) = nxⁿ⁻¹
d/dx(sin x) = cos x
d/dx(cos x) = -sin x
d/dx(eˣ) = eˣ
d/dx(log x) = 1/x

Product Rule

d(uv)/dx = u(dv/dx) + v(du/dx)

Quotient Rule

d(u/v)/dx = [v(du/dx)-u(dv/dx)]/v²

6. Applications of Derivatives

Rate of Change

Derivative represents the instantaneous rate of change of one quantity with respect to another.

dy/dx

Increasing Function

f'(x) > 0

Decreasing Function

f'(x) < 0

Maximum / Minimum

Critical points are generally found by solving:

f'(x) = 0
Exam Tip: Sirf f'(x)=0 milna maximum/minimum prove nahi karta. Second derivative or sign-change test check karo.

7. Integrals

Basic Integration

∫xⁿ dx = xⁿ⁺¹/(n+1) + C
∫1/x dx = log|x| + C
∫eˣ dx = eˣ + C
∫sin x dx = -cos x + C
∫cos x dx = sin x + C

Integration by Parts

∫u dv = uv - ∫v du

Definite Integral

∫ₐᵇ f(x) dx
Remember: Indefinite integration mein +C lagana mat bhoolna.

8. Applications of Integrals

Area Under Curve

A definite integral can be used to calculate area bounded by a curve and coordinate axes or other curves.

Area = ∫ₐᵇ y dx

Agar curve x-axis ke neeche ho, area ko positive magnitude ke form mein consider karna hota hai.

Example:
For y = x² between x=0 and x=2:

Area = ∫₀² x² dx

9. Differential Equations

Differential Equation

An equation involving derivatives of a dependent variable with respect to an independent variable is called a differential equation.

Order

The highest order derivative present in the equation determines its order.

Degree

When the differential equation is polynomial in derivatives, the highest power of the highest order derivative gives its degree.

Basic Form

dy/dx = f(x)
y = ∫f(x)dx + C

10. Vector Algebra

Vector

A quantity having both magnitude and direction is called a vector.

Magnitude

|a| = √(a₁² + a₂² + a₃²)

Dot Product

a · b = |a||b|cosθ

Cross Product

|a × b| = |a||b|sinθ
Remember: Dot product gives a scalar quantity, while cross product gives a vector quantity.

11. Three Dimensional Geometry

Direction Cosines

If l, m and n are direction cosines:

l² + m² + n² = 1

Distance Between Two Points

d = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]

Line in 3D

(x-x₁)/a = (y-y₁)/b = (z-z₁)/c

12. Linear Programming

Linear Programming Problem

A problem in which we maximize or minimize a linear objective function subject to linear constraints.

Important Terms

  • Objective Function
  • Constraints
  • Feasible Region
  • Optimal Solution
Z = ax + by
Exam Tip: Graphical method mein feasible region identify karna aur corner points check karna important hai.
