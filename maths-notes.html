UNIT 1 — Differential Calculus

1. Taylor's Theorem

Taylor's theorem is used to expand a function around a particular point.

f(x) = f(a) + (x-a)f'(a) + (x-a)²/2! f''(a) + (x-a)³/3! f'''(a) + ...
Example:
Expansion of eˣ about x = 0:

eˣ = 1 + x + x²/2! + x³/3! + ...

2. Maclaurin's Theorem

Maclaurin series is a special case of Taylor series where a = 0.

f(x) = f(0) + xf'(0) + x²/2! f''(0) + x³/3! f'''(0) + ...

Important expansions:

eˣ = 1 + x + x²/2! + x³/3! + ...

sin x = x - x³/3! + x⁵/5! - ...

cos x = 1 - x²/2! + x⁴/4! - ...

log(1+x) = x - x²/2 + x³/3 - x⁴/4 + ...

3. Partial Differentiation

When a function contains more than one independent variable, differentiation with respect to one variable while keeping the other variables constant is called partial differentiation.

If z = f(x,y), then:

∂z/∂x = differentiation with respect to x
∂z/∂y = differentiation with respect to y
Example:
z = x²y + 3xy²

∂z/∂x = 2xy + 3y²
∂z/∂y = x² + 6xy

4. Euler's Theorem

If z is a homogeneous function of degree n, then:

x(∂z/∂x) + y(∂z/∂y) = nz

5. Maxima and Minima of Two Variables

For z = f(x,y), first find:

fₓ = 0
fᵧ = 0

Then calculate:

D = fₓₓ fᵧᵧ - (fₓᵧ)²
  • D > 0 and fₓₓ > 0 → Minimum
  • D > 0 and fₓₓ < 0 → Maximum
  • D < 0 → Saddle point
  • D = 0 → Test is inconclusive

6. Curvature

Curvature measures how rapidly a curve changes its direction.

For y = f(x):

Radius of curvature:
ρ = [1 + (dy/dx)²]³ᐟ² / |d²y/dx²|

UNIT 2 — Integral Calculus

1. Definite Integral

A definite integral has fixed limits.

∫ₐᵇ f(x) dx = F(b) − F(a)
Example:
∫₀¹ x² dx

= [x³/3]₀¹
= 1/3

2. Beta Function

B(m,n) = ∫₀¹ xᵐ⁻¹(1-x)ⁿ⁻¹ dx

Important relation:

B(m,n) = Γ(m)Γ(n) / Γ(m+n)

3. Gamma Function

Γ(n) = ∫₀∞ e⁻ˣ xⁿ⁻¹ dx

For positive integer n:

Γ(n) = (n-1)!
Example:
Γ(5) = 4! = 24

4. Double Integral

Double integration is used to find areas and other quantities over a two-dimensional region.

∫∫ᴿ f(x,y) dA

The order of integration can sometimes be changed according to the given region.

5. Triple Integral

Triple integrals are used mainly for calculating volumes and other three-dimensional quantities.

∫∫∫ᵥ f(x,y,z) dV

UNIT 3 — Differential Equations

1. Differential Equation

An equation involving derivatives of an unknown function is called a differential equation.

Example:
dy/dx + y = x

2. Exact Differential Equation

A first-order differential equation is written as:

M dx + N dy = 0

It is exact if:

∂M/∂y = ∂N/∂x

3. Linear Differential Equation

dy/dx + Py = Q

Integrating Factor:

IF = e^(∫P dx)

Solution:

y × IF = ∫(Q × IF) dx + C

4. Clairaut's Equation

y = px + f(p)

where p = dy/dx

Differentiate with respect to x and obtain the general and singular solutions.

5. Linear Differential Equation with Constant Coefficients

f(D)y = X

where D = d/dx.

General solution:

Complete Solution = C.F. + P.I.
  • C.F. = Complementary Function
  • P.I. = Particular Integral

6. Variation of Parameters

Variation of parameters is a method used to find the particular solution of certain non-homogeneous differential equations.

y = C₁y₁ + C₂y₂

The constants are replaced by functions and determined using the standard variation-of-parameters procedure.

UNIT 4 — Matrices

1. Rank of a Matrix

The rank of a matrix is the maximum number of linearly independent rows or columns.

Rank can be found using elementary row or column transformations.

2. System of Linear Equations

A system of equations can be written in matrix form as:

AX = B

The system can be solved using elementary transformations.

3. Consistency of Equations

For AX = B:

If rank(A) = rank(A|B) → System is consistent

If rank(A) ≠ rank(A|B) → System is inconsistent

4. Eigen Values

Eigen values are obtained from:

|A − λI| = 0

The roots of this equation are the eigen values.

Example:
For a 2 × 2 matrix A, form |A − λI| = 0 and solve the resulting characteristic equation.

5. Eigen Vectors

For each eigen value λ, the corresponding eigen vector X satisfies:

(A − λI)X = 0

6. Cayley-Hamilton Theorem

Every square matrix satisfies its own characteristic equation.

If characteristic equation is:
λⁿ + a₁λⁿ⁻¹ + ... + aₙ = 0

Then:
Aⁿ + a₁Aⁿ⁻¹ + ... + aₙI = 0

It can be used to calculate higher powers and, when appropriate, the inverse of a matrix.

📝 Unit 4 Practice

2. When is AX = B consistent?

When rank(A) = rank(A|B).

UNIT 5 — Logic, Boolean Algebra & Graph Theory

1. Algebra of Logic

Logic algebra deals with statements that can have truth values such as True or False.

AND → A · B
OR → A + B
NOT → A'

2. Boolean Algebra

Important Boolean identities:

A + 0 = A
A · 1 = A
A + 1 = 1
A · 0 = 0
A + A = A
A · A = A
A + A' = 1
A · A' = 0

3. Principle of Duality

In Boolean algebra, the dual of an expression can be obtained by interchanging:

+ ↔ ·
0 ↔ 1

4. Fuzzy Logic

Unlike classical Boolean logic, fuzzy logic allows partial membership between 0 and 1.

Example:
A person may be considered "warm" with membership value 0.7 rather than simply True or False.

5. Graph Theory

A graph consists of vertices and edges.

G = (V,E)

V = Set of vertices
E = Set of edges

6. Degree of a Vertex

Degree of a vertex is the number of edges incident with that vertex.

Sum of degrees of all vertices = 2 × Number of edges

7. Tree

A tree is a connected graph without any cycle.

For a tree:
Number of edges = Number of vertices − 1

8. Cycle and Network

A cycle is a closed path that starts and ends at the same vertex without repeating intermediate vertices.

A network is a graph used to represent interconnected objects or systems.
