📐 Mathematics

```

Sets

  • Union: A ∪ B = elements in A or B or both.
  • Intersection: A ∩ B = common elements of A and B.
  • Difference: A − B = elements of A but not B.
  • Complement: A' = elements not belonging to A.
n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

Trigonometry

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ
tan θ = sin θ / cos θ

Complex Numbers

  • i = √−1
  • i² = −1
  • General form: z = a + ib
  • Real part = a
  • Imaginary part = b
|z| = √(a² + b²)

Quadratic Equation

ax² + bx + c = 0
x = (−b ± √(b² − 4ac)) / 2a
D = b² − 4ac
  • D > 0 → two distinct real roots
  • D = 0 → equal real roots
  • D < 0 → no real roots

Sequence & Series

AP nth term: aₙ = a + (n−1)d
AP Sum: Sₙ = n/2 [2a + (n−1)d]
Arithmetic Mean = (a+b)/2
```

⚡ Physics

```

Motion in Straight Line

v = u + at
s = ut + ½at²
v² = u² + 2as
s = (u+v)t / 2
  • u = initial velocity
  • v = final velocity
  • a = acceleration
  • s = displacement
  • t = time

Newton's Laws of Motion

  • First law: An object maintains its state unless an external force acts on it.
  • Second law relates force, mass and acceleration.
  • Third law: Every action has an equal and opposite reaction.
F = ma
p = mv

Work, Energy & Power

W = Fs cosθ
K.E. = ½mv²
P.E. = mgh
Power = Work / Time

Gravitation

F = Gm₁m₂ / r²
g = GM / R²
  • G = universal gravitational constant
  • M = mass of Earth/body
  • R = radius

Thermodynamics

ΔQ = ΔU + ΔW
  • ΔQ = heat supplied
  • ΔU = change in internal energy
  • ΔW = work done
```

🧪 Chemistry

```

Mole Concept

Number of moles = Given mass / Molar mass
Number of particles = moles × 6.022 × 10²³
  • 1 mole contains approximately 6.022 × 10²³ particles.
  • Molar mass is expressed in g/mol.

Structure of Atom

  • Electron → negative charge
  • Proton → positive charge
  • Neutron → no charge
  • Atomic number = number of protons
  • Mass number = protons + neutrons

Chemical Bonding

  • Ionic bond → transfer of electrons
  • Covalent bond → sharing of electrons
  • Valence electrons strongly influence bonding.

Thermodynamics

ΔU = q + w
  • ΔU = change in internal energy
  • q = heat
  • w = work

Redox Reaction

  • Oxidation → loss of electrons / increase in oxidation state.
  • Reduction → gain of electrons / decrease in oxidation state.
  • Oxidation and reduction occur together in a redox reaction.

Hydrocarbons

Alkanes → CₙH₂ₙ₊₂
Alkenes → CₙH₂ₙ
Alkynes → CₙH₂ₙ₋₂
```

💻 Computer Science / IP

```

Python Basics

print("Hello")
x = 10
if x > 5: print("Greater")
  • Variable stores a value.
  • Python is dynamically typed.
  • Indentation is important in Python.

Important Operators

+ − * / // % **
  • + → addition
  • − → subtraction
  • * → multiplication
  • / → division
  • // → floor division
  • % → remainder
  • ** → power

Lists

numbers = [10, 20, 30]
numbers.append(40)
  • List is ordered.
  • List is mutable.
  • Indexing starts from 0.

Dictionaries

student = {"name":"Rahul", "age":17}
  • Dictionary stores data as key-value pairs.
  • Keys are used to access values.

SQL Basics

SELECT * FROM students;
SELECT name FROM students WHERE age > 17;
  • SELECT → retrieve data
  • WHERE → condition
  • INSERT → add data
  • UPDATE → modify data
  • DELETE → remove data
```

📝 Important Definitions

```

Mathematics

  • Set: A well-defined collection of objects.
  • Function: A relation where every input has exactly one output.
  • Sequence: An ordered list of numbers.

Physics

  • Displacement: Change in position of an object.
  • Velocity: Rate of change of displacement.
  • Acceleration: Rate of change of velocity.
  • Force: Interaction capable of changing motion.

Chemistry

  • Atom: Smallest unit of an element that retains its chemical identity.
  • Molecule: Group of atoms held together by chemical bonds.
  • Ion: Charged atom or group of atoms.

Computer

  • Algorithm: Step-by-step procedure for solving a problem.
  • Database: Organized collection of data.
  • SQL: Language used to manage and query relational databases.
```
